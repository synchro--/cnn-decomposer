// Tucker & CPD compression for conv layers — framework-agnostic roadmap

// 01 — User Flow

STEP 01
Import
from tensorpress import Compressor from tensorpress import CompressConfig
STEP 02
Instantiate Model
model = ResNet50() # any nn.Module # TF / JAX future
STEP 03
Configure
cfg = CompressConfig( method="tucker", layers="all", ranks="auto", finetune=True )
STEP 04
Compress
c = Compressor(cfg) result = c.compress( model, dataloader) result.report()
STEP 05
Evaluate
result.compare() result.export( "compressed.pt")

// Key Design Decisions
Config: dataclass-based, fully serializable JSON / YAML round-trip for reproducibility LayerSelector: "all" → every Conv2d ["layer1","layer2"] → named regex → flexible matching lambda → custom predicate RankEstimator: "auto" → VBMF heuristic float → compression ratio dict → per-layer manual ranks Decomposition: ABC with .decompose(weight) returns factorized nn.Sequential Backend: ABC isolates framework ops PyTorch ships in v1 TF/JAX via same interface Result: .report() → rich table .compare() → side-by-side .export() → save state dict
