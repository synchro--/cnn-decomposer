# Roadmap

## v0.1 (current)

- Tucker and CPD for `Conv2d`
- PyTorch backend
- Auto rank estimation with VBMF
- Optional fine-tuning

## v0.2

- SVD decomposition
- Rank sensitivity analysis
- `@compress_model` decorator

## v0.3

- TensorFlow backend
- JAX backend

## v1.0

- Structured pruning integration
- Quantization-aware compression
- ONNX export support

## v2.0

- Non-computer-vision model examples and tests
- Compression workflows for sequence, tabular, and multimodal models
